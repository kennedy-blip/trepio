# Trepio Wiki

Welcome to the Trepio project wiki! This is the comprehensive documentation for the Trepio 3D candy kingdom game.

## Overview

Trepio is a handcrafted 3D **candy-fantasy kingdom** that runs entirely in your browser — no servers, no accounts, no downloads. Built with Three.js and vanilla JavaScript.

- **Repository**: https://github.com/kennedy-blip/trepio
- **Live Demo**: https://kennedy-blip.github.io/trepio/
- **Version**: 3.4.0

## Features

- 🎭 **9 Playable Characters** — Each with unique stats, personalities, and quests
- 👑 **Royal Family** — 6 NPCs living in the palace with their own storylines
- 🏰 **Explorable World** — Candy-cane maze, lollipop forest, rainbow river, gumdrop village, grand palace
- 📜 **Quest System** — 10+ quests with branching dialogue and rewards
- 🏠 **Player Homes** — 5 unique home interiors with furniture and sitting mechanics
- 🐾 **Pet System** — 6 pet types that follow you and can be fed/petted
- 🎮 **Arcade Mini-Games** — Candy Catch, Gummy Rush, Whack-a-Mole, Simon Says
- 💾 **Save/Export** — LocalStorage persistence with file export/import
- 🎨 **Deep Customization** — Hair, outfits, accessories, colors for both genders
- 📱 **Mobile Support** — Touch controls and responsive UI
